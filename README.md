# 幸运抽奖系统（多空间版）

同一个网址下，每位发起者用自己的 PIN 创建独立抽奖空间；参与者通过空间专属链接进入。支持转盘 / 随机开奖、多奖项同抽、每人唯一 CDK、中奖冷却、定时开奖、实时同步、Excel/TXT 导出，以及 Excel / Word / TXT 人员名单导入与编辑。

- 入口页（参与者输空间码 / 发起者输 PIN / 创建空间）：`/`
- 参与者页：`/s/{空间码}`
- 发起者后台：`/s/{空间码}/admin`
- 健康检查：`/healthz`

发起者在首页创建空间时自设 PIN（全局唯一），之后只输 PIN 即可进入自己的后台。每个空间的人员、奖项、中奖记录、定时任务和导出都彼此隔离，只有该空间的发起者能导出或删除记录。

> 免费实例的磁盘是临时的，重启后会清空**所有空间**。请在活动结束后立即导出中奖记录归档。
